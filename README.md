# שולה מוקשים - Minesweeper Deluxe 💣

משחק שולה מוקשים מלא, מודרני וקלאסי בקובץ HTML יחיד ועצמאי!

## ✨ מאפיינים ויתרונות (Features)

- **קובץ יחיד ועצמאי לחלוטין (Single Standalone File):** כל הקוד, העיצוב (CSS), הלוגיקה (JavaScript), האייקונים (SVGs) והצלילים מרוכזים בתוך `index.html` אחד ללא תלויות חיצוניות.
- **תמונות וגרפיקה איכותית (Graphics & Assets):**
  - דגל סימון קלאסי
  - מוקש ימי קוצני אותנטי
  - מוקש שהתפוצץ ואפקט להבה
  - מוקש שגוי (סימון שגוי שהתגלה בסיום)
  - סמיילי אינטראקטיבי המגיב ללחיצות (שמח, מפוחד בעת לחיצה, מת בהפסד, מרכיב משקפי שמש בניצחון)
- **מנוע סאונד מובנה (Web Audio API Synthesizer):** אפקטי קול ייחודיים ללחיצות, הנחת דגלים, פיצוץ וצליל ניצחון חגיגי ללא צורך בקובצי שמע חיצוניים.
- **מנגנוני משחק מתקדמים:**
  - **פתיחה ראשונה בטוחה ב-100% (Guaranteed Safe First Click):** הלחיצה הראשונה שלכם לעולם לא תפגע במוקש ותפתח אזור נקי.
  - **Chording (פתיחה מהירה):** לחיצה על מספר שסביבו כבר מוקמו מספיק דגלים תפתח מיידית את שאר המשבצות הסמוכות.
  - **שעון דיגיטלי וסופר מוקשים:** תצוגת 7-Segment בעיצוב רטרו קלאסי.
  - **רמות קושי מגוונות:**
    - מתחיל: 9×9 עם 10 מוקשים
    - מתקדם: 16×16 עם 40 מוקשים
    - מומחה: 30×16 עם 99 מוקשים
    - התאמה אישית: בחירת גודל לוח וכמות מוקשים כרצונכם
  - **שמירת שיאים (High Scores):** שמירת הזמן הטוב ביותר בכל רמת קושי ב-`localStorage`.
  - **ערכות נושא (Themes):** מעבר בין עיצוב רטרו נוסטלגי (Windows 95/98) לבין עיצוב Dark Modern עתידני.
  - **אנימציית קונפטי בניצחון:** אפקט חגיגי מלא במסך.
  - **תמיכה מלאה במובייל ומסכי מגע:** לחיצה ארוכה לסימון דגלים.

## 🚀 איך מפעילים?
פשוט פתחו את `index.html` ישירות בכל דפדפן מודרני (Chrome, Edge, Firefox, Safari) או הריצו שרת מקומי.
